# Use OpenRouter in Chorus for Android

This guide is for **Chorus – All AI, One Place**, the Android app by AIHUB, package `com.aihub.app`.

1. Install [Chorus from Google Play](https://play.google.com/store/apps/details?id=com.aihub.app), sign in and verify your Chorus account.
2. Create or select an API key in your own [OpenRouter account](https://openrouter.ai/settings/keys). Keep the key private.
3. Open Chorus's provider connections (Gateways), add a connection and choose the **OpenRouter** preset. The preset uses `https://openrouter.ai/api/v1`.
4. Enter your OpenRouter API key and save the connection. Choose a model available to your account, then try one short chat before a larger task.
5. To compare models, use **Compare** with the same prompt and inspect both answers. Comparing models makes multiple provider requests.

Chorus has no app subscription. Provider charges, account credits, quotas and model availability apply separately. A provider's consumer chat subscription does not necessarily include API access. See [OpenRouter's current limits](https://openrouter.ai/docs/api-reference/limits).

If setup fails, check the selected preset, key validity and provider account access. Share the error wording with support after removing keys and private content. Never post an API key in a public message or screenshot.
